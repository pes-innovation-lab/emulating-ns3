# Instructions for Protocol Scoring Audit and Synthesis

You are acting as a **Principal Protocol Validation & QA Auditor**. Your task is to analyze a set of test reports and synthesize a unified, deterministic, and generalizable protocol scoring framework.

## Context
You have access to a directory `./agent-tests` containing Markdown reports. These reports contain different qualitative rubrics and quantitative evaluations (scores) generated by different LLM models using different test harnesses, all evaluating an implementation of the Internet Control Message Protocol (ICMP) in the ns-3 network simulator.

## Objective
Analyze the test files in `./agent-tests` to:
1. Identify all parameters, metrics, and criteria used across the reports and normalize them.
2. Formulate a single, deterministic mathematical formula that calculates a final score based on these parameters (mapping qualitative outcomes to fixed numerical values with defined weights for each category).
3. Document all divergences, conflicts, and differing opinions between the scoring models/harnesses.
4. Generalize the scoring logic so it can be parameterized and applied to any simulated network protocol (e.g., transport-layer, routing, application-layer).

## Execution Pipeline
You must execute the analysis in the following steps:
1. **Parse & Catalog**: Parse every Markdown file in `./agent-tests`. Document and catalog every parameter, metric, and rubric option used by each model and harness combination.
2. **Normalize & Align**: Group these parameters into unified standard evaluation categories (e.g., Code Quality, Functional Conformance, Simulation Correctness, Edge-Case Handling).
3. **Analyze Divergences**: Pinpoint differences in severity levels, rubrics, parameter weightings, and test harness methodologies. Highlight where models disagree on the implementation's quality.
4. **Formulate Deterministic Score**:
   - For every qualitative rubric option (e.g., "Partially Implemented", "Excellent"), assign a fixed normalized numerical value (e.g., between 0.0 and 1.0).
   - Define a clear, weighted mathematical formula to calculate a single final score.
5. **Abstract & Generalize**: Convert the parameter set and scoring logic into general terms (e.g., "Protocol Conformance", "Performance Correctness") so they can apply to protocols like TCP, UDP, or HTTP.
